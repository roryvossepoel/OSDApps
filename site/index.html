How it works

From Windows installation to OOBE.

One flow. Your apps and configuration, applied before OOBE.

  1. 01

    Windows deployment · WinPE

    Install Windows

    Apply Windows with OSDCloud or another deployment method. The examples use OSDCloud.

  2. 02

    OSDStage · WinPE

    Stage your choices

    Stage the apps and configuration you choose. If an OSDCloud-labeled USB drive is connected, supported content can be cached and reused automatically.

  3. 03

    Windows 11 · SetupComplete

    Apply automatically

    Restart into Windows. SetupComplete installs your apps, runs Windows Update when selected and applies configuration before OOBE.

  4. 04

    Windows 11 · OOBE

    Continue setup

    Review your delivery report, then continue with Windows setup, Autopilot device preparation, classic Autopilot or your own provisioning flow.

Evergreen built-ins

Current when you deploy.

Before installation, OSDStage checks for the latest supported version, caches it when needed, and then installs it. Built-in app integrations stay evergreen.

Every deployment leaves a clear record. Open the offline HTML report to see what succeeded, what changed and what needs your attention.

  • Apps, with their source. See which apps came from built-in integrations and which came from your own repository.
  • Details behind the result. Expand fonts, certificates, settings and file operations.
  • An honest handover. See update results, restart requirements and evidence checks together.
  • A result you can act on. Quickly spot what succeeded, what needs attention and what to check next.
