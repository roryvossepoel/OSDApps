Why OSDStage

Prepare more before the user takes over.

OSDStage was created with Windows Autopilot device preparation in mind. Device preparation currently has no pre-provisioning mode; Microsoft lists pre-provisioning and self-deploying scenarios as future support. OSDStage does not replace enrollment. It simply lets a bare-metal deployment complete selected preparation work earlier.

01 · Your selection

Move selected work before OOBE.

Choose the apps, Windows updates and device configuration that make sense for the device. Use OSDStage built-ins, packages from your own repository, or both.

ExamplesApps · Windows Update · Registry · Services · Certificates · Files

02 · Management stays separate

Autopilot and Intune still do their job.

OSDStage does not perform Microsoft Entra join, MDM enrollment or Autopilot registration. For managed devices, keep required apps assigned through Intune or your other application-management platform so their normal lifecycle still applies after resets or later deployments.

OSDStageBare-metal preparationMDM / application managementEnrollment · policy · ongoing lifecycle

03 · Deployment choice

Designed around OSDCloud. Not tied to it.

OSDStage is designed and tested primarily around OSDCloud, Windows Autopilot and Microsoft Intune. OSDCloud is not a technical dependency: another deployment method can be used if Windows has already been applied and OSDStage can stage the target before its first boot.

Natural fitOSDCloud → OSDStage → SetupCompleteAlso possibleAnother Windows deployment method → OSDStage

Microsoft documents pre-provisioning and self-deploying as future Windows Autopilot device preparation scenarios. Microsoft FAQ ↗ · Working with Device Association too? Windows Device Link ↗

How it works

From Windows installation to OOBE.

One flow. Your apps and configuration, applied before OOBE.

  1. 01

    Windows deployment · WinPE

    Install Windows

    Apply Windows with OSDCloud or another deployment method. The examples use OSDCloud.

  2. 02

    OSDStage · WinPE

    Stage your choices

    Stage the apps and configuration you choose. If an OSDCloud-labeled USB drive is connected, supported content can be cached and reused automatically.

  3. 03

    Windows 11 · SetupComplete

    Apply automatically

    Restart into Windows. SetupComplete installs your apps, runs Windows Update when selected and applies configuration before OOBE.

  4. 04

    Windows 11 · OOBE

    Continue setup

    Review your delivery report, then continue with Windows setup, Autopilot device preparation, classic Autopilot or your own provisioning flow.

03 · Caching

Download once.
Reuse when it matches.

Caching is optional. Online deployments can acquire supported content without USB; a connected OSDCloud-labeled volume can reuse matching content across devices.

Online source→OSDStage→Device
↕Optional USB cachereuse matching content

For a fully offline deployment, prepare and verify all required matching content before first boot.

How caching works →

Managing the same app with Intune or another MDM/application platform? Keep it assigned there for lifecycle and reset scenarios, and make sure its detection logic recognizes the version installed by OSDStage—especially for evergreen integrations.
