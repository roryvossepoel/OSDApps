Your first deployment

Three steps. One normal deployment.

Start with two built-in apps on an online x64 device.

Development candidate OSDStage is not on the PowerShell Gallery yet. Use the reviewed CI module artifact below.
01
On your preparation PC · Full Windows

Put the module on your USB.

Open a successful CI run for main. Download OSDStage-PowerShell-7 from its Artifacts section; GitHub sign-in may be required.

Extract the module into \Modules\OSDStage\ on your OSDCloud USB. Keep all module folders together. The manifest should be at \Modules\OSDStage\OSDStage.psd1.

Open module downloads ↗

The artifact name identifies its CI job. The module also supports Windows PowerShell 5.1.

02
On the target PC · WinPE

Load the module. Choose your apps.

Let OSDCloud apply Windows first. Run this before the first Windows boot. The USB drive letter is detected automatically.

PowerShell
$usb = @(Get-Volume | Where-Object {
    $_.FileSystemLabel -eq 'OSDCloud' -and $_.DriveLetter
})
if ($usb.Count -ne 1) { throw 'Connect one OSDCloud USB drive.' }
$module = Join-Path "$($usb[0].DriveLetter):\" 'Modules\OSDStage\OSDStage.psd1'
Import-Module $module -Force -ErrorAction Stop
PowerShell
Add-OSDStageGoogleChromeEnterprise -Architecture x64
Add-OSDStageAdobeAcrobatUnified -Architecture x64

These commands stage the selection. Installation happens during the next step.

03
Same WinPE session → first Windows boot

Check the queue. Continue your deployment.

PowerShell
Test-OSDStageDeployment -ThrowOnFailure |
    Format-List Valid, OfflineReady, NetworkRequired, PackageCount

Expect Valid: True and PackageCount: 2 on a fresh test. OfflineReady: False is normal when content still needs to download.

Use your normal deployment restart. Keep the PC online and the USB connected until OOBE appears. SetupComplete downloads the content as needed and installs your selections in order.

Where can I see the result?

On the deployed Windows device, after SetupComplete:

PowerShell
$result = Get-Content "$env:ProgramData\OSDStage\Results\Latest.json" -Raw |
    ConvertFrom-Json
$result | Format-List Status, SuccessfulPackageCount, FailedPackageCount
$result.Packages | Format-Table Id, Status, ExitCode

Reaching OOBE alone does not prove every package succeeded.
