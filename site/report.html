Status with context

A green installation result is only part of the story.

The report separates execution from follow-up work. Matching evidence connects the details to the same deployment; missing or stale details are shown honestly.

Succeeded

Execution and checks passed.

No recorded restart or update follow-up requires attention. This describes the recorded run.

Attention

Review the next step.

Execution may have succeeded, while a restart, skipped result, missing evidence or another update scan needs review.

Failed

A failure was recorded.

Review the affected package and local runtime logs. Independent work can still have succeeded.

After SetupComplete · On the deployed PC

Your report is already there.

The default folder is %ProgramData%\OSDStage\Results. Open the HTML on the deployed PC or copy it to a preparation PC with a browser. If you configured a different runtime result path, the report sits beside that result file.

PowerShell · deployed Windows after SetupComplete
$results = Join-Path $env:ProgramData 'OSDStage\Results'
Start-Process (Join-Path $results 'DeliveryReport.html')

In OOBE, you can inspect the JSON from an elevated console after the runner finishes. If a browser is not available yet, copy the HTML to your preparation PC.

Read the structured report · no module import needed
$report = Get-Content (Join-Path $results 'DeliveryReport.json') -Raw |
    ConvertFrom-Json
$report | Format-List Status, ExecutionStatus, RebootRequired
$report.Checks | Format-Table Name, Passed, Detail -Wrap

Keep the result in context.

The report is written after runner completion, or after terminal PreInstall failure. It is a record of that execution: it does not refresh after a later reboot or certify device health, active driver binding, complete patch coverage or Autopilot enrollment.

Credential and configuration values are omitted, but device/component names, certificate identifiers and target paths remain. Review a real report before sharing it. Keep the original runtime logs for detailed troubleshooting.
